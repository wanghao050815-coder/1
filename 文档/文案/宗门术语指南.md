# 宗门术语使用指南

> 基于 337 条真实文案数据统计，仅含实际使用过的术语。

## 核心术语表

| 术语 | 含义 | 出现频率 | 使用场景 | 示例 |
|------|------|---------|---------|------|
| **秘法** | 核心训练方法/技巧 | 15次 | 推荐动作时 | "宗主传你一个秘法" |
| **宗主** | 博主本人（邪健仙） | 9次 | 权威推荐时 | "练宗主的修炼功法" |
| **邪修** | 粉丝群体/团队 | 7次 | 身份认同时 | "对于我们邪修来说" |
| **正派** | 传统/主流健身方法 | 5次 | 对比反差时 | "正派跟你说要先减脂" |
| **先修** | 粉丝/学员称呼 | 3次 | 亲切称呼时 | "先修的，跟你说" |
| **宗门弟子** | 粉丝（更正式） | 2次 | 集体称呼时 | "对于咱们宗门弟子来说" |

## 使用规则

### 数量限制
- 每条文案 **3-5个** 宗门术语
- 不可超过 5 个（过多会显得刻意）
- 不可少于 1 个（保持品牌辨识度）

### 植入强度（按内容支柱）
| 内容支柱 | 强度 | 术语数 | 说明 |
|---------|------|--------|------|
| 训练方法 | 低 | 2-3个 | 术语替换 + 片尾口号 |
| 营养饮食 | 低 | 2-3个 | 术语替换 + 片尾口号 |
| 健康生活 | 中 | 4-5个 | 自然使用称呼和术语 |
| 热点追踪 | 低 | 仅片尾 | 热点内容以通用性为主 |
| 品牌合作 | 低 | 仅品牌露出 | 不混用宗门和商业 |
| 宗门IP | 高 | 5个+ | 大量使用宗门体系 |

### 绝对禁区
以下术语在真实文案中**从未出现**，不可使用：

| 虚构术语 | 出现次数 | 说明 |
|---------|---------|------|
| 心法 | 0 | 容易联想到武侠小说，与健身场景不搭 |
| 绝学 | 0 | 过度中二化 |
| 道法 | 0 | 宗教感太强 |
| 武学 | 0 | 武术方向，与健身无关 |
| 功力 | 0 | 过于玄幻 |

### 注意事项
1. 首次出现的术语用括号注释日常含义，方便新粉理解
2. 不能用宗门身份排斥非粉丝
3. 不能过度中二化
4. 不能在商业合作内容中大量使用宗门术语
5. 宗门口号「邪修正道，百炼飞仙」仅在合适场景使用

## 常见搭配

### 开篇搭配
```
"对于我们邪修来说啊，..."
"对于咱们宗门弟子来说，..."
"先修的，跟你说..."
```

### 转折搭配
```
"正派跟你说啊，[传统方法]。而对我们邪修来说，..."
"别听正派瞎说，宗主传你一个秘法..."
```

### CTA搭配
```
"加入邪修带你抄近路！"
"宗主带你抄近路！"
```
