# 文案部门 SOP（标准作业流程）

## 部门定位

文案部门是团队内容生产链条中的核心文字输出环节，负责所有平台的文案创作、优化和话术体系维护。文案部门与内容策划、视频剪辑、社区运营紧密协作，确保每一条发布内容的文字表达符合品牌声音、平台规范和用户预期。

---

## 职责范围

| 职责 | 说明 |
|------|------|
| 视频脚本撰写 | 根据内容策划提供的 Brief，撰写口播/旁白脚本 |
| 标题与描述优化 | 为各平台撰写标题、视频描述、话题标签文案 |
| 封面文案设计 | 配合视觉规范，撰写封面标题文字 |
| 图文内容创作 | 小红书笔记、微博博文、微信推文等图文类内容 |
| 话术库维护 | 维护评论区互动话术、直播口播模板、社群运营话术 |
| 商务文案配合 | 品牌合作、广告植入等商务内容的文案撰写 |
| 文案数据复盘 | 分析文案效果（标题点击率、完播率、互动率），持续迭代 |

## 工作流程

### 1. 需求接收

```
触发方式：
├── GitHub Issue（文案需求申请模板）  ← 主要方式
├── 内容日历排期自动触发
└── 团队会议口头需求 → 需补提 Issue
```

- 所有文案需求必须通过 GitHub Issue 提交，使用「文案需求申请」模板
- 文案编辑在收到 Issue 后 **24小时内** 确认需求并回复排期
- 如需求信息不完整，文案编辑应在 Issue 中 @需求方补充

### 2. 文案撰写

**撰写前检查清单：**
- [ ] 已阅读品牌声音指南（`docs/brand/brand-voice-guide.md`）
- [ ] 已确认目标平台的文案规范和字数限制
- [ ] 已了解关联内容的拍摄/制作进度
- [ ] 已检查近期同类型文案避免重复表达

**撰写规范：**

| 平台 | 标题字数 | 描述字数 | 特殊要求 |
|------|---------|---------|---------|
| 抖音 | 10-20字 | 50-150字 | 前3秒hook必须抓人，标题需含关键词 |
| 小红书 | 15-20字 | 300-800字 | 标题需有数字或疑问句，正文分段清晰 |
| 微博 | 不限 | 140字内（长微博除外） | 善用话题标签，文案口语化 |
| B站 | 10-25字 | 100-300字 | 标题信息量大，描述含时间戳 |
| 微信 | 15-25字 | 根据推文长度 | 标题需引发好奇，摘要精炼 |

### 3. 内部审核

```
文案编辑初稿
    ↓
内容策划审核（内容准确性、选题匹配度）
    ↓
创作者终审（品牌调性、敏感内容把关）
    ↓
通过 → 进入发布流程
    ↓
需修改 → 返回文案编辑修改，标注具体修改意见
```

- 审核通过后在 Issue 中标记 `copy/approved`
- 需修改时在 Issue 中标记 `copy/revision-needed` 并说明修改要求
- 单条文案最多修改 **3轮**，超过3轮需重新评估需求

### 4. 文案归档

- 已发布文案归档至 `data/copy_library/` 目录
- 按平台和内容支柱分类存储
- 高互动文案（互动率超平台均值2倍）标记为「金句库」素材

## 文案质量标准

### 必须遵守
- 符合品牌声音指南中定义的人设和语气
- 不含未经验证的医疗/健康声明
- 不使用竞品品牌名（除对比类内容且经创作者批准）
- 不含违禁词和平台敏感词
- 宗门IP相关文案需使用标准术语体系

### 质量评分维度
| 维度 | 权重 | 说明 |
|------|------|------|
| 信息准确性 | 30% | 健身知识点是否正确、有依据 |
| 品牌一致性 | 25% | 是否符合品牌声音和人设 |
| 平台适配度 | 20% | 是否符合平台调性和用户阅读习惯 |
| 互动引导力 | 15% | CTA是否自然、能否激发互动 |
| 创意与差异化 | 10% | 是否有新颖表达、区别于竞品 |

## 平台文案公式

### 抖音视频脚本结构
```
[0-3秒] Hook开场 → 痛点/反常识/数字冲击
[3-10秒] 问题阐述 → 引发共鸣
[10-45秒] 核心内容 → 3个要点（每点10秒内讲完）
[45-55秒] 总结收尾 → 金句/宗门梗
[55-60秒] CTA → 关注/评论/收藏引导
```

### 小红书笔记结构
```
标题：数字 + 痛点/结果（例：「练了3个月腿还是细？因为你忽略了这1个动作」）
正文：
  第一段 → 痛点共鸣（2-3句）
  要点列表 → 核心干货（3-5条，带emoji分隔）
  结尾 → 互动引导 + 话题标签
```

### 微博博文结构
```
Hook开头（1句话抓注意力）
+ 核心观点（2-3句）
+ 互动提问
+ 话题标签（2-3个）
```

## 协作规范

### 与内容策划协作
- 内容策划完成 Brief 后，在 Issue 中 @文案编辑
- Brief 应包含：核心信息点、目标受众、参考素材、期望CTA
- 文案编辑收到 Brief 后确认理解无误再开始撰写

### 与视频剪辑协作
- 脚本完成后同步给视频剪辑，说明需要配合的画面要求
- 脚本中用 `[画面：xxx]` 标注视觉配合需求
- 成片字幕与脚本不一致时，需文案编辑确认

### 与社区运营协作
- 评论区高频问题整理后反馈给文案部门，作为选题参考
- 互动话术模板由文案部门统一维护，社区运营按模板回复
- 敏感评论的回复话术需经创作者审核

## KPI 指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 文案按时交付率 | ≥95% | 在约定排期内完成交付 |
| 审核一次通过率 | ≥70% | 初稿通过内部审核，无需修改 |
| 标题点击率提升 | 月环比+5% | 通过A/B测试持续优化标题 |
| 金句库更新 | ≥10条/月 | 从高互动内容中提取优质文案 |
| 话术库覆盖率 | ≥90% | 常见互动场景均有标准话术 |
