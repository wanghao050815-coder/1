# B1 代运营功能指南

> 邪修宗多账号代运营系统 (feature/agency-management)

## 功能概览

B1 阶段实现了完整的多账号管理和代运营工作流，支持：

- ✅ 多账号隔离管理（B1主号、B2子号、B3子号）
- ✅ 账号权限控制（full、publish、read_only）
- ✅ 周报自动生成（TOP 3 分析 + 优化建议）
- ✅ 月报自动生成（趋势分析 + KPI 对标）
- ✅ KPI 追踪和预警
- ✅ 跨账号数据对比

## 账号配置

### 初始化账号

账号配置存储在 `/数据/accounts/account.json`：

```json
{
  "accounts": {
    "B1": {
      "name": "邪健仙主号",
      "type": "master",
      "permission": "full",
      "platforms": {"douyin": "邪健仙", ...}
    },
    "B2": {
      "name": "邪修宗男团号",
      "type": "sub",
      "master": "B1",
      "permission": "publish"
    },
    "B3": {
      "name": "邪修宗女团号",
      "type": "sub",
      "master": "B1",
      "permission": "publish"
    }
  }
}
```

### 账号类型

- **master**：主账号，拥有完整控制权（full permission）
- **sub**：子账号，受权限限制（publish 或 read_only）
- **standalone**：独立账号，完全独立运营

### 权限级别

| 权限 | copywrite | publish | analytics | manage |
|------|-----------|---------|-----------|--------|
| full | ✓ | ✓ | ✓ | ✓ |
| publish | ✗ | ✓ | ✗ | ✗ |
| read_only | ✗ | ✗ | ✓ | ✗ |

## CLI 使用

### 1. 生成文案（支持多账号）

```bash
# B1 生成文案（默认）
python -m tools.agents copywrite --topic "腹肌训练" --platform douyin --pillar training

# B2 生成文案
python -m tools.agents copywrite --topic "腹肌训练" --account B2 --platform douyin

# 指定简报和语气
python -m tools.agents copywrite \
  --topic "腹肌训练" \
  --account B1 \
  --brief "高强度HIIT，3分钟见效" \
  --tone "激励式，专业权威"
```

### 2. 生成周报

```bash
# 准备周数据文件（metrics.json）
{
  "week_start": "2026-03-31",
  "followers": 185000,
  "engagement_rate": 0.052,
  "completion_rate": 0.35,
  "post_count": 7,
  "pillar_distribution": {
    "training": 4,
    "sect_ip": 2,
    "trending": 1
  },
  "top_3_copies": [
    {
      "title": "腹肌秘诀",
      "likes": 12500,
      "comments": 450,
      "shares": 1200,
      "hook_type": "反问梗式",
      "cta_type": "效果承诺型",
      "category": "腹肌/核心"
    },
    ...
  ]
}

# 生成 B1 周报
python -m tools.agents agency-weekly \
  --account B1 \
  --input metrics.json

# 输出：周报 Markdown + JSON
# 保存位置：/数据/accounts/B1/代运营/周报/
```

### 3. 生成月报

```bash
# 准备周报汇总和 KPI 数据
# weekly.json：4 周周报的汇总
# kpi.json：{target: {...}, actual: {...}}

python -m tools.agents agency-monthly \
  --account B1 \
  --weekly weekly.json \
  --kpi kpi.json

# 输出：月报包含趋势、KPI对标、策略建议
```

### 4. KPI 总结

```bash
python -m tools.agents agency-kpi \
  --account B1 \
  --input kpi-tracking.json

# 输出：红/黄/绿预警 + 改进建议
```

### 5. 跨账号洞察

```bash
# 对比 B1、B2、B3 的表现
python -m tools.agents agency-insights \
  --input multi-account-comparison.json

# 输出：最佳实践、互补建议、统一管理建议
```

## 常见问题

### Q: 如何添加新账号（如 B4）？

```python
from tools.agents.shared.account import AccountManager

mgr = AccountManager(Path("数据"))
mgr.create_account(
    account_id="B4",
    account_name="邪修宗第四号",
    account_type="sub",
    permission="publish",
    master="B1"
)
```

### Q: 如何修改账号权限？

直接编辑 `/数据/accounts/account.json`，修改对应账号的 `permission` 字段。

### Q: 旧数据如何迁移？

目前支持单账号模式（B1），旧数据继续存储在 `/数据/文案/`。

新的多账号数据存储在 `/数据/accounts/{account_id}/`。

### Q: 子账号可以添加自己的子账号吗？

不支持。当前支持：master → sub（一级），不支持多级嵌套。
