## 一、算法信号优先级

抖音算法对以下行为信号的权重从高到低排列：

| 优先级 | 信号 | 说明 |
|--------|------|------|
| 1 | **完播率** | 观看到最后一帧的比例，最关键指标。目标：>40% |
| 2 | **点赞率** | 点赞数 / 播放数。目标：>3% |
| 3 | **评论率** | 评论数 / 播放数。鼓励有争议性的良性问题诱导评论 |
| 4 | **转发率** | 转发数 / 播放数。转发到私聊权重低于转发到朋友圈 |
| 5 | **关注转化** | 因本视频新增的关注。优质内容的副产品，不可强求 |

**核心原则：优先保住完播率，其次是点赞，再考虑其他。**

- 如果前3秒不够吸引人，一切白搭
- 完播率低于20%的视频，系统会限流，DOU+也救不回来
- 评论区互动（回复评论、置顶评论）会刷新内容热度，发布后30分钟内务必维护评论区

## 二、视频时长策略

根据内容类型选择合适时长：

### 日常健身小贴士（15-30秒）
- 适用：单个动作示范、营养小知识、打卡激励
- 结构：钩子(3s) → 核心内容(20s) → CTA(5s)
- 完播率目标：>60%
- 注意：超过30秒需明显的情节钩子维持观看

### 动作教学教程（60-90秒）
- 适用：完整动作分解、训练组合、饮食搭配教学
- 结构：钩子(5s) → 问题提出(10s) → 步骤演示(60s) → 总结+CTA(15s)
- 完播率目标：>35%
- 技巧：在30秒处设置"悬念节点"，防止用户流失

### 深度内容（3-5分钟）
- 适用：训练计划详解、减脂误区辟谣、专题系列
- 结构：钩子(10s) → 内容预告(20s) → 主体分段讲解 → 总结(30s) → CTA(20s)
- 完播率目标：>25%
- 关键：每60秒设置一个"信息节点"，给用户继续看的理由

## 四、话题标签策略

**公式：1个泛流量词 + 2个精准垂类词 + 1个品牌词（最多5个）**

| 类型 | 示例 | 作用 |
|------|------|------|
| 泛流量词（1个） | #健身 #减肥 #运动 | 进入大流量池，获取基础曝光 |
| 精准垂类词（2个） | #居家训练 #腹部燃脂 #蛋白质摄入 | 触达精准用户，完播率更高 |
| 品牌词（1个） | #[博主账号名] | 积累品牌搜索量，培养用户习惯 |
| 可选补充（1个） | 当前热门话题 | 蹭热度，需与内容相关 |

**注意事项：**
- 不要堆砌超过5个话题，过多反而分散权重
- 话题要与视频内容高度相关，平台会识别话题匹配度
- 定期（每月）更新话题词库，关注新兴垂类话题

## 五、封面图规范

### 尺寸要求
- **尺寸**：1080 × 1920 像素（9:16 竖版）
- **安全区**：顶部和底部各留出10%（约192px）不放关键信息
  - 顶部：抖音界面会遮挡
  - 底部：话题标签、账号名会遮挡

### 视觉设计要求
- 主标题文字：字号不小于60pt，使用高对比度颜色（白色+黑色描边 或 黄色+黑色描边）
- 人物出镜封面：主体居中或左三分之一，右侧放文字
- 背景：避免纯黑、纯白（在用户feed中对比度过强/过弱）
- 品牌一致性：统一使用品牌色系 [品牌主色] + [品牌辅助色]

### 封面文案公式
- 问题型：「为什么你练了3个月没效果？」
- 数字型：「5个动作消灭拜拜肉」
- 对比型：「吃这个 vs 吃那个，差距有多大」
- 否定型：「停止这3个减肥错误」

## 六、开头3秒钩子公式

开头3秒决定用户是否继续看，以下是经过验证的钩子公式：

### 公式一：痛点直击
> 「你是不是练了好几个月，肚子还是一点没变？」

### 公式二：反常识陈述
> 「有氧运动其实不是减脂最好的方式——」

### 公式三：数字冲击
> 「90%的人做平板支撑都是错的」

### 公式四：直接承诺
> 「今天教你一个动作，练3周腰围减3厘米」

### 公式五：悬念设置
> 「我减掉20斤之后，后悔没早知道这件事——」

### 公式六：现场展示
- 直接从动作示范开始，配文字：「这个动作你一定做错过」
- 无需语言，视觉冲击直接进入主题

**使用规则：**
- 钩子必须与正文内容强相关，不能标题党
- 情绪类钩子（焦虑、惊喜）转化率高，但不能过度煽情
- 测试不同钩子，记录完播率差异

## 七、文案结构

```
【钩子陈述】（1句话，对应视频开头问题）
↓
核心观点1：[内容]
核心观点2：[内容]
核心观点3：[内容]（最多3点，超过会被折叠）
↓
【行动号召（CTA）】
```

**CTA示例：**
- 关注号召：「关注我，每天分享健身干货」
- 互动号召：「你有哪个动作做不标准？评论区告诉我」
- 保存号召：「收藏备用，别让自己又重新找」
- 话题号召：「参与话题 #[话题名] 晒出你的打卡」

**文案禁忌：**
- 不要出现「点击主页链接」类导流话术（违规风险）
- 不要出现联系方式（手机号、微信号）
- 不要使用夸大效果词（如「三天减十斤」「100%有效」）

## 八、DOU+ 投放策略

### 何时考虑投放 DOU+

**必须满足以下门槛后才考虑投放：**
- 自然流量完播率 ≥ 35%
- 点赞率 ≥ 2%
- 发布后2小时内获得 ≥ 500 次自然播放

**不要投放的情况：**
- 完播率 < 20%（内容本身有问题，投钱也救不回）
- 发布后5分钟内立即投（系统需要时间判断内容质量）
- 内容涉及违规词汇或画面（可能被平台限流且浪费预算）

### 投放参数设置

| 参数 | 建议设置 |
|------|----------|
| 投放目标 | 视频播放量（粉丝增长期）/ 主页访问（变现期）|
| 受众 | 系统智能推荐（新账号期）/ 自定义兴趣标签（成熟账号）|
| 投放时长 | 6小时（测试）/ 24小时（放量）|
| 起投金额 | 100元（测试）→ 效果好再追加 |

### 评估投放效果
- 投放后CPM < 15元 = 优秀
- 投放后CPM 15–30元 = 正常
- 投放后CPM > 30元 = 受众匹配差，停止投放

## 十一、100万→300万增长阶段策略

百万粉级别是抖音的「中腰部瓶颈区」，突破这一区间需要从「靠运气出爆款」转向「系统化制造爆款」。

### Phase 1：100万→150万（夯实爆款公式）

**核心任务：找到3个可复制的爆款模板**

- 回顾过去6个月所有超均值3倍的视频，提炼共同要素（选题类型、钩子公式、时长、发布时间）
- 将爆款要素拆解为可填入的模板：`[钩子类型] + [内容结构] + [CTA类型]`
- 每周至少1条使用爆款模板制作的内容，持续验证和迭代
- 本阶段不追求平台数量，集中火力打抖音

### Phase 2：150万→220万（合拍引流+矩阵放量）

**核心任务：打开新流量入口**

- 启动合拍/连线策略：每月至少2次与同量级或更大博主连线
- 考虑建立矩阵号（如「XX的日常」），用日常内容做流量补充
- 爆款内容跨平台分发：抖音爆款 → 裁剪后发小红书/B站
- 直播常态化：每周1-2场，直播切片二次分发

### Phase 3：220万→300万（IP破圈+私域双引擎）

**核心任务：从健身博主升级为健身IP**

- 策划出圈事件：挑战赛、公益活动、跨界合作
- 私域导流提速：直播间引导加入粉丝群，粉丝群专属内容预告
- 品牌合作反哺增长：选择自带流量的品牌合作，利用品牌曝光涨粉

## 十二、爆款内容复制公式

### 爆款识别标准
- 播放量 ≥ 近30天平均值 × 3
- 完播率 ≥ 50%
- 涨粉数 ≥ 单条平均涨粉 × 5

### 爆款拆解模板

每次出现爆款后，必须在24小时内完成以下拆解：

```
1. 选题切入点：______（哪个痛点/好奇心被激发了？）
2. 钩子类型：______（用了上述6种钩子中的哪种？）
3. 内容结构：______（信息密度如何？节奏是否紧凑？）
4. 封面设计：______（文案用了什么公式？画面构图？）
5. 发布时间：______（星期几几点？是否在黄金时段？）
6. 评论区表现：______（前10条评论说了什么？是否有争议？）
7. 可复制元素：______（哪些要素可以直接套用到下一条？）
```

### 复制策略

- **换题不换结构**：同样的内容结构，换一个相关话题重做
- **换平台不换核心**：爆款内容适配后发其他平台
- **做系列**：爆款选题拓展为3-5集系列
- **评论区选题**：从爆款评论区中挖掘下一条选题

## 十三、直播涨粉策略

### 直播频率与时长
- **频率**：每周1-2场（稳定期可增至3场）
- **时长**：90-120分钟为最佳（太短缺乏推流势能，太长疲劳）
- **黄金时段**：周二/四 20:00-22:00，周末 10:00-12:00

### 直播内容结构

```
开场热身（10分钟）
  → 打招呼 + 预告今天内容 + 引导关注
主题教学（40分钟）
  → 实操动作教学 / 营养问答 / 训练计划定制
互动环节（30分钟）
  → 粉丝连线 / 体态评估 / 问题解答
收尾（10分钟）
  → 总结 + 预告下次直播 + 引导关注和加粉丝群
```

### 直播涨粉技巧
- 每15分钟口播一次「新来的朋友点个关注，等下教你XX」
- 设置「关注后解锁」的互动环节（如抽奖、连线名额仅限粉丝）
- 直播中制造金句/名场面，方便后续切片传播
- 直播结束后2小时内发布2-3条直播切片（精华片段+引导回放）

### 直播切片规范
- 时长：15-60秒
- 必须保留完整的信息点（不要截断一句话中间）
- 添加字幕和封面文案
- 标题带「直播回放」「直播名场面」关键词
- 发布时间：直播结束后2小时、次日中午、次日晚间

## 十四、评论区运营（涨粉隐形杠杆）

评论区互动直接影响算法推流权重，是最被低估的涨粉手段。

### 评论引导策略

**结尾设计引导评论的话术：**
- 二选一提问：「你更倾向A方案还是B方案？评论区告诉我」
- 挑战邀请：「试完这个动作的在评论区打个✅」
- 争议性观点：「我知道很多人不同意，但...你觉得呢？」
- 悬念延续：「下一集教哪个动作？评论区票数最高的我来拍」

### 评论区置顶策略
- 发布后立即用小号或团队账号发一条有引导性的评论并置顶
- 置顶评论内容：补充信息、引导关注、提出问题
- 示例：「新来的朋友：这个系列一共5集，关注后不迷路，第2集明天发」

### 回复策略
- 发布后30分钟内回复前10条评论（激活算法推流）
- 优先回复有内容的评论（而非"666"之类的）
- 回复时引导进一步互动：「你说的这个问题，我专门出一期讲」

## 十五、搜索SEO优化

抖音搜索流量占比持续增长，是长尾涨粉的重要渠道。

### 标题SEO策略
- 在标题中嵌入1-2个搜索热词（通过「创作灵感」查看近期热搜词）
- 标题结构：`热搜词 + 痛点/好奇心`
- 示例：「减脂期能吃米饭吗？90%的人都理解错了」（"减脂"+"米饭"均为热搜词）

### 描述SEO策略
- 描述区补充3-5个长尾搜索词
- 用自然语句嵌入，避免堆砌
- 示例：「这个居家腹肌训练适合新手，不需要任何器械，每天10分钟就够了」

### 合集优化
- 将同类内容加入合集（合集出现在搜索结果中概率更高）
- 合集标题使用搜索热词
- 每个合集控制在5-10条视频

## 十六、单条视频72小时数据分析法

每条视频发布后，按以下时间节点分析数据，快速决策是否追投：

### 数据追踪时间线

| 时间节点 | 关注指标 | 决策 |
|----------|----------|------|
| 发布后1小时 | 完播率、前3秒跳出率 | 完播率<20%→内容本身有问题，不投 |
| 发布后6小时 | 播放量、互动率 | 播放量>1000且互动率>5%→考虑DOU+测试 |
| 发布后24小时 | 播放量曲线、涨粉数 | 仍在上升→追投DOU+；已平稳→停止 |
| 发布后48小时 | 总播放量、投产比 | 如果已投DOU+，计算CPM是否<15元 |
| 发布后72小时 | 最终数据 | 归档数据，录入爆款分析模板（如适用） |

### 快速判断公式

```
是否追投 = (完播率 ≥ 35%) AND (6小时播放 ≥ 1000) AND (互动率 ≥ 3%)
```

如果三个条件都满足，说明内容质量过关且有爆款潜力，可以追投DOU+加速。

## 十七、合拍与连线引流策略

合拍和连线是百万粉级别最有效的涨粉方式之一。

### 连线对象选择标准
- 粉丝量级：50万-500万（太小无效，太大对方可能不接受）
- 内容领域：健身同行 > 健康饮食 > 运动品牌 > 生活方式
- 粉丝画像重叠度：对方的粉丝也是你的目标受众
- 近期活跃度：对方近30天有稳定更新

### 连线内容设计
- **PK型**：谁的训练方式更有效？（制造话题性）
- **互补型**：健身博主×营养师 联合答疑（扩大覆盖面）
- **挑战型**：互相挑战对方不擅长的训练（娱乐性+专业性）
- **教学型**：一方教一方学（展示教学能力）

### 连线流程
1. 提前3-5天私信/邮件联系，发送合作提案
2. 确定主题和大纲，双方各准备3-5个话题点
3. 直播连线30-60分钟，双方各自在自己账号开播
4. 连线结束后各自发布切片，互相@对方
