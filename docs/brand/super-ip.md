## 一、宗门概述

### 什么是"宗门"

"宗门"是我们围绕账号构建的粉丝社群文化体系。它不是简单的粉丝群名称，而是一整套语言、符号、仪式和价值观——让关注者从"路人"变成"弟子"，从"看内容"变成"归属一个组织"。

### 为什么做宗门 IP

| 维度 | 普通粉丝运营 | 宗门 IP 运营 |
|------|------------|-------------|
| 用户关系 | 博主→观众（单向） | 掌门→弟子（双向归属） |
| 留存动力 | 内容质量 | 内容质量 + 身份认同 + 社群归属 |
| 互动深度 | 点赞、评论 | 使用宗门术语、参与仪式、产出 UGC |
| 防御壁垒 | 低（容易被替代） | 高（文化迁移成本高） |
| 变现基础 | 流量变现 | 流量 + 社群 + 品牌信仰变现 |

## 三、宗门话语体系

### 3.1 核心称呼

| 标准称呼 | 指代 | 使用场景 |
|---------|------|---------|
| 掌门 | 创作者本人 | 粉丝对博主的称呼 |
| 弟子 | 所有粉丝/关注者 | 博主对粉丝的统称 |
| 入门弟子 | 新关注的粉丝 | 新粉欢迎语 |
| 内门弟子 | 活跃粉丝（评论/互动频繁） | 互动激励 |
| 亲传弟子 | 核心粉丝/私域社群成员 | 私域社群专属称呼 |
| 长老 | 资深粉丝/社群管理员 | 粉丝层级最高称呼 |
| 同门 | 粉丝之间互称 | 评论区粉丝互动 |

### 3.2 训练术语替换

| 日常用语 | 宗门术语 | 使用示例 |
|---------|---------|---------|
| 健身/训练 | 修炼 | 「今天的修炼内容是——」 |
| 训练计划 | 功法 | 「这套功法适合入门弟子」 |
| 训练日 | 修炼日 | 「周一是上肢修炼日」 |
| 休息日 | 闭关/恢复期 | 「今天闭关一天，让肌肉恢复」 |
| 完成训练 | 完成修炼/打卡 | 「今日修炼已完成」 |
| 增肌 | 炼体 | 「炼体阶段要多吃」 |
| 减脂 | 蜕变 | 「蜕变期饮食这样安排」 |
| 突破瓶颈 | 突破境界/渡劫 | 「卧推渡劫成功！」 |
| 受伤/疲劳 | 走火入魔 | 「训练过度小心走火入魔」 |
| 蛋白质 | 灵丹（玩笑式） | 「修炼后别忘了吃灵丹」 |

### 3.3 术语使用规则

| 规则 | 说明 |
|------|------|
| 频率控制 | 每条内容中宗门术语不超过 3-5 个，避免过度中二 |
| 场景适配 | 专业教学内容少用术语，生活/互动内容多用 |
| 新粉友好 | 首次使用术语时，用括号补充日常含义 |
| 不强制 | 不要求所有粉丝都用术语，自然渗透 |

## 四、宗门仪式感体系

### 4.1 入门仪式

**触发条件：** 新粉关注后首次评论

**标准回复模板：**
> 欢迎入门！从今天起你就是邪修宗的弟子了。记住宗训第一条：日练不辍。第一课从这里开始 → [置顶视频链接]

### 4.2 日常仪式

| 仪式 | 频率 | 形式 | 说明 |
|------|------|------|------|
| 晨修打卡 | 每日 | 评论区/社群 | 弟子晒出当日训练内容 |
| 每周试炼 | 每周 | 视频挑战 | 掌门发布周挑战动作，弟子跟练打卡 |
| 月度论道 | 每月 | 直播/社群 | 掌门答疑、弟子分享心得 |
| 渡劫庆祝 | 不定期 | 评论区/社群 | 弟子突破个人记录时，全宗庆祝 |

### 4.3 成就体系

| 成就名称 | 达成条件 | 奖励/认可 |
|---------|---------|----------|
| 入门礼成 | 关注 + 首次评论 | 欢迎回复 |
| 七日筑基 | 连续 7 天打卡 | 评论区点名表扬 |
| 月度精进 | 连续 30 天打卡 | 私域社群邀请（晋升内门弟子） |
| 百日蜕变 | 完成 100 天训练 + 身材对比图 | 视频中展示其成果 |
| 渡劫成功 | 突破个人训练记录 | 掌门视频回复祝贺 |
| 传道授业 | 带动 3 位新人加入 | 授予"长老"称号 |

## 六、宗门运营规范

### 6.1 内容植入指南

| 内容类型 | 宗门元素植入方式 | 植入强度 |
|---------|-----------------|---------|
| 训练教程 | 用术语替换2-3个关键词 + 片尾口号 | 低 |
| 营养饮食 | 片尾一句宗门梗 | 低 |
| 生活方式 | 自然使用称呼和术语 | 中 |
| 互动内容 | 大量使用宗门体系 | 高 |
| 社群活动 | 完全使用宗门体系 | 最高 |

### 6.2 评论区宗门运营

**标准互动话术：**

| 粉丝评论场景 | 宗门风格回复 |
|-------------|------------|
| 新粉首次评论 | 「欢迎入门，同门又多一位！」 |
| 打卡晒成果 | 「修炼有成！继续精进，距离渡劫不远了」 |
| 请教问题 | 「好问题，掌门来解答——」 |
| 表达感谢 | 「同门之间不必客气，一起进步」 |
| 突破记录 | 「恭喜渡劫成功！全宗为你贺！🔥」 |

### 6.3 宗门红线

| 禁止行为 | 原因 |
|---------|------|
| 用宗门体系排斥非粉丝 | 制造对立，影响拉新 |
| 过度中二化严肃内容 | 削弱专业性 |
| 用宗门身份进行商业施压 | 如"弟子就该支持掌门的推荐" |
| 宗门等级与付费挂钩 | 破坏社群信任 |
| 抄袭其他博主的社群体系 | 缺乏原创性，粉丝能辨别 |

## 七、宗门 KPI

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| 私域社群月增长率 | ≥ 10% | 社群人数月环比 |
| 用户 UGC 产出 | ≥ 50 条/月 | 带宗门标签的用户内容 |
| 宗门术语使用率 | ≥ 20% | 评论区中主动使用术语的比率 |
| 老粉二次观看率 | ≥ 30% | 老粉丝对新内容的观看率 |
| 社区 NPS | ≥ 60 | 季度社群满意度调研 |

## 八、宗门演进路线

| 阶段 | 粉丝量级 | 重点动作 |
|------|---------|---------|
| **立宗期** | 0-10 万 | 确立名称、术语、基础仪式，让核心粉丝开始使用 |
| **传道期** | 10-50 万 | 完善成就体系，启动私域社群，培养第一批"长老" |
| **兴宗期** | 50-100 万 | 推出宗门周边、线下活动，UGC 爆发增长 |
| **盛宗期** | 100 万+ | 宗门文化自运转，粉丝主动传播，考虑IP衍生 |
