## 一、总则

视觉识别标准确保团队在所有平台上的视觉输出保持一致性和专业感。所有封面、字幕、图文排版、社群素材都必须遵循本文档规范。

**核心原则：**
- **一致性** — 用户在任何平台看到内容，3 秒内能认出"这是我们的"
- **可读性** — 信息传达优先，装饰性元素服务于内容
- **高效复用** — 建立模板体系，降低每条内容的设计成本

## 二、品牌色彩体系

> 以下色值需由创作者与视觉设计师确认后填写。

### 2.1 主色

| 名称 | 色值 | 用途 |
|------|------|------|
| 品牌主色 | `#[HEX值]` | 封面标题、强调元素、品牌徽章 |
| 品牌辅助色 | `#[HEX值]` | 次要标题、图标、分隔线 |

### 2.2 中性色

| 名称 | 色值 | 用途 |
|------|------|------|
| 深色背景 | `#1A1A2E` | 深色系封面背景、字幕条 |
| 浅色背景 | `#F5F5F5` | 图文类内容背景 |
| 正文文字色 | `#333333` | 图文正文 |
| 次要文字色 | `#999999` | 说明文字、水印 |

### 2.3 功能色

| 名称 | 色值 | 用途 |
|------|------|------|
| 成功/正确 | `#27AE60` | 动作正确示范标注 |
| 警告/错误 | `#E74C3C` | 动作错误示范标注、禁止标记 |
| 提示/信息 | `#F39C12` | 注意事项、重点提醒 |

### 2.4 色彩使用规则

- 单张封面最多使用 3 种颜色（主色 + 辅助色 + 中性色）
- 品牌主色面积占比不低于 15%，确保品牌辨识度
- 避免大面积纯黑（`#000000`）或纯白（`#FFFFFF`）作为背景
- 正确/错误对比图中，必须使用功能色标注，不可使用其他颜色

## 三、字体规范

### 3.1 指定字体

| 用途 | 中文字体 | 英文/数字字体 | 备选 |
|------|---------|-------------|------|
| 封面主标题 | [指定字体，如"优设标题黑"] | [如 Montserrat Bold] | [备选字体] |
| 封面副标题 | [指定字体，如"思源黑体 Bold"] | [如 Montserrat Medium] | [备选字体] |
| 视频字幕 | [指定字体，如"思源黑体 Regular"] | [如 Roboto Regular] | [备选字体] |
| 图文正文 | [指定字体，如"思源宋体 Regular"] | [如 Inter Regular] | [备选字体] |

### 3.2 字号规范

#### 视频封面（1080 × 1920）

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 主标题 | 60-80pt | Bold/Heavy | 白色 + 黑色描边(3px) 或 品牌主色 |
| 副标题 | 36-48pt | Medium | 品牌辅助色 或 浅灰 |
| 角标/标签 | 24-30pt | Bold | 白色（品牌主色背景色块上） |

#### 视频字幕

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 主字幕 | 36-42pt | Medium | 白色 + 黑色描边(2px) |
| 重点强调词 | 42-48pt | Bold | 品牌主色 或 功能色 |
| 补充说明 | 28-32pt | Regular | 浅灰色 |

#### 图文内容（小红书/微信）

| 元素 | 字号 | 字重 |
|------|------|------|
| 标题 | 24-28pt | Bold |
| 正文 | 16-18pt | Regular |
| 注释/来源 | 12-14pt | Light |

### 3.3 字体使用红线

- 禁止在同一画面中使用超过 2 种字体
- 禁止使用系统默认字体（如宋体、微软雅黑）作为封面标题
- 所有字体必须确认商用授权，避免版权风险
- 字幕文字必须有描边或底色条，确保在任何背景上可读

## 四、封面设计规范

### 4.1 尺寸要求

| 平台 | 封面尺寸 | 比例 | 安全区 |
|------|---------|------|--------|
| 抖音 | 1080 × 1920 px | 9:16 | 上下各留 10%（192px） |
| 小红书（竖版） | 1080 × 1440 px | 3:4 | 上下各留 8% |
| 小红书（方形） | 1080 × 1080 px | 1:1 | 四周各留 5% |
| B站 | 1920 × 1080 px | 16:9 | 右下角留出 120×80px（时长标签） |
| 微信封面 | 900 × 383 px | 2.35:1 | 居中 60% 区域放关键信息 |
| 微博 | 1920 × 1080 px | 16:9 | 四周各留 5% |

### 4.2 封面布局模板

#### 模板 A：人物 + 文字（最常用）

```
┌─────────────────────┐
│    [安全区-顶部]      │
│                      │
│  ┌──────┐  ┌──────┐  │
│  │      │  │ 主标题│  │
│  │ 人物  │  │      │  │
│  │ 出镜  │  │ 副标题│  │
│  │      │  │      │  │
│  └──────┘  └──────┘  │
│                      │
│  [品牌角标]           │
│    [安全区-底部]      │
└─────────────────────┘
```

- 人物占画面左 1/3 至 1/2
- 文字占画面右 1/2 至 2/3
- 人物视线方向朝向文字侧

#### 模板 B：纯文字（教程/列表类）

```
┌─────────────────────┐
│    [安全区-顶部]      │
│                      │
│    ┌──────────────┐  │
│    │   主标题      │  │
│    │   （大字）     │  │
│    ├──────────────┤  │
│    │   副标题/     │  │
│    │   要点列表    │  │
│    └──────────────┘  │
│                      │
│  [品牌角标]           │
│    [安全区-底部]      │
└─────────────────────┘
```

- 主标题居中偏上
- 背景使用品牌色渐变或模糊图片

#### 模板 C：对比型（before/after）

```
┌──────────┬──────────┐
│          │          │
│  BEFORE  │  AFTER   │
│   ❌     │   ✅     │
│          │          │
│  [错误]   │  [正确]  │
│          │          │
└──────────┴──────────┘
```

- 左右分割，使用功能色标注
- 错误侧使用红色标记，正确侧使用绿色标记

### 4.3 封面质量检查清单

- [ ] 主标题在手机屏幕上缩小后仍然清晰可读？
- [ ] 关键信息不在安全区之外？
- [ ] 使用了品牌指定字体和色彩？
- [ ] 人物出镜图像清晰、光线充足？
- [ ] 品牌角标/水印已添加？
- [ ] 无竞品水印或未授权素材？

## 五、视频画面规范

### 5.1 拍摄参数

| 参数 | 竖版视频 | 横版视频 |
|------|---------|---------|
| 分辨率 | 1080 × 1920 | 1920 × 1080 |
| 帧率 | 30fps（常规）/ 60fps（动作慢放） | 30fps / 60fps |
| 码率 | ≥ 10 Mbps | ≥ 15 Mbps |
| 白平衡 | 手动锁定，保持画面色温一致 | 同左 |

### 5.2 字幕规范

| 要素 | 规范 |
|------|------|
| 字幕位置 | 画面下方 1/4 处，不遮挡人物面部 |
| 字幕行数 | 最多 2 行，每行不超过 15 字 |
| 字幕样式 | 白色文字 + 黑色描边（2px），重点词用品牌主色 |
| 字幕时长 | 每屏字幕显示不少于 2 秒 |

### 5.3 动作标注规范

训练教程类视频中，需对动作要点进行画面标注：

| 标注类型 | 样式 | 颜色 |
|---------|------|------|
| 正确动作 | 实线箭头 + ✅ | 绿色 `#27AE60` |
| 错误动作 | 虚线箭头 + ❌ | 红色 `#E74C3C` |
| 发力方向 | 弧线箭头 | 品牌主色 |
| 肌肉部位 | 高亮区域 | 品牌辅助色（40% 透明度） |

### 5.4 片头片尾

| 元素 | 片头 | 片尾 |
|------|------|------|
| 时长 | 无固定片头（直接进入内容） | 3-5 秒 |
| 内容 | — | 品牌 logo + 宗门口号 + 关注引导 |
| 音效 | — | [指定品牌音效] |

## 六、图文排版规范

### 6.1 小红书图文

| 要素 | 规范 |
|------|------|
| 封面图 | 3:4 竖版，使用模板 A 或 B |
| 内页图 | 统一尺寸、统一背景色，每页一个核心信息 |
| 图片数量 | 6-9 张（含封面） |
| 排版风格 | 干净、留白充足、信息密度适中 |
| 每页文字量 | 不超过 80 字 |

### 6.2 微信推文

| 要素 | 规范 |
|------|------|
| 头图 | 900 × 383 px |
| 正文配图 | 宽度 1080px，高度按需 |
| 段落间距 | 1.75 倍行距 |
| 正文字号 | 16px |
| 重点标记 | 使用品牌主色加粗，不使用其他颜色 |

## 七、水印与品牌标识

### 7.1 水印规范

| 要素 | 规范 |
|------|------|
| 内容 | 账号名称（文字，非 logo） |
| 位置 | 视频：右上角或左下角；图片：右下角 |
| 透明度 | 30-50%（不影响内容观看） |
| 字号 | 视频：24pt；图片：18pt |
| 颜色 | 白色（深色背景）/ 深灰色（浅色背景） |

### 7.2 品牌角标

| 要素 | 规范 |
|------|------|
| 位置 | 封面左上角或右上角 |
| 大小 | 不超过封面面积的 5% |
| 内容 | 宗门徽章 或 内容系列标签（如"掌门课堂"） |

## 八、素材管理规范

### 8.1 文件命名规则

```
[日期]_[平台]_[支柱]_[类型]_[序号].[格式]

示例：
20260330_douyin_training_cover_01.png
20260330_douyin_training_video_01.mp4
20260330_xhs_nutrition_page_03.jpg
```

### 8.2 文件夹结构

```
assets/
├── templates/         # 封面/排版模板（PSD/Figma）
│   ├── cover-person-text.psd
│   ├── cover-text-only.psd
│   └── cover-comparison.psd
├── brand/             # 品牌素材（logo、字体、色卡）
│   ├── logo/
│   ├── fonts/
│   └── color-palette.png
├── weekly/            # 按周归档的产出素材
│   └── 2026-W14/
│       ├── covers/
│       ├── subtitles/
│       └── thumbnails/
└── stock/             # 可复用的通用素材
    ├── backgrounds/
    ├── icons/
    └── overlays/
```

### 8.3 素材交付标准

| 交付物 | 格式 | 分辨率 | 备注 |
|--------|------|--------|------|
| 封面图 | PNG | 按平台规范 | 含可编辑源文件（PSD/Figma） |
| 视频成片 | MP4 (H.264) | 1080p+ | 码率 ≥ 10Mbps |
| 图文内页 | PNG | 1080px 宽 | 按页编号 |
| 字幕文件 | SRT | — | 时间轴精确到帧 |
