## 一、品牌人设定位

### 核心身份

我们是一位 **真实、专业、有温度** 的健身伙伴——不是高高在上的教练，而是你身边那个已经踩过坑、走过弯路、愿意把经验毫无保留分享给你的朋友。

### 人设关键词（5 个）

| 关键词 | 含义 | 对应内容表现 |
|--------|------|-------------|
| **真实** | 不美化、不造假，展示真实训练过程和身材变化 | 素颜出镜、承认失败、展示未修图数据 |
| **专业** | 内容有依据、有逻辑，不传播伪科学 | 引用研究、纠错常见误区、动作细节讲解到位 |
| **亲和** | 没有距离感，像朋友聊天一样说话 | 口语化表达、自嘲、日常化场景 |
| **务实** | 给可执行的方案，不贩卖焦虑 | 具体动作/食谱/计划，不说"你必须这样" |
| **热血** | 保持正向能量，激励但不鸡汤 | 用自身经历激励，偶尔燃一下，但不空喊口号 |

### 一句话人设描述

> 「一个练了X年的普通人，把踩过的每一个坑都变成了你的捷径。」

## 二、语气光谱

根据不同内容类型，语气在以下光谱上滑动：

```
严肃/专业 ◄──────────────────────► 轻松/日常
   │                                    │
   ├─ 动作纠错、安全提醒               ├─ 日常vlog、打卡分享
   ├─ 营养科普、辟谣内容               ├─ 评论区互动
   └─ 商务合作内容                     └─ 宗门梗、粉丝互动
```

### 语气使用规则

| 内容类型 | 语气定位 | 示例 |
|----------|---------|------|
| 训练教程 | 专业偏亲和（6:4） | 「这个动作很多人做错了，我之前也是——注意肘关节不要超伸」 |
| 营养饮食 | 专业偏务实（7:3） | 「减脂期碳水不是不能吃，关键是选对时机和种类」 |
| 生活方式 | 亲和偏热血（3:7） | 「今天练完最后一组的时候差点站不起来，但站起来那一刻真的爽」 |
| 辟谣纠错 | 严肃偏专业（8:2） | 「这个说法没有任何科学依据，实际情况是——」 |
| 宗门互动 | 轻松偏热血（2:8） | 「宗门弟子们，今天的修炼任务完成了吗？」 |
| 商务合作 | 专业偏真实（6:4） | 「这款产品我自己用了两个月，说说真实感受——」 |

## 三、写作规范

### 3.1 用词原则

#### 推荐用词

| 场景 | 推荐 | 避免 |
|------|------|------|
| 称呼粉丝 | 兄弟们、姐妹们、各位、宗门弟子 | 亲、宝宝、家人们（过度亲昵） |
| 称呼自己 | 我 | 小编、本博主（第三人称感太强） |
| 表达建议 | 可以试试、我的做法是、推荐你 | 你必须、你应该、不这样做就（命令感） |
| 表达效果 | 我的体验是、数据显示、研究表明 | 100%有效、三天见效、绝对管用 |
| 表达困难 | 确实不容易、需要时间、慢慢来 | 太简单了、谁都能做到（否定用户感受） |

#### 禁用词清单

| 类别 | 禁用词/表达 | 原因 |
|------|------------|------|
| 医疗声明 | 治疗、治愈、根治、药到病除 | 法律风险 |
| 绝对化用语 | 100%、绝对、肯定、一定能 | 广告法违规 |
| 贬低用语 | 胖子、肥猪、废物、菜鸡 | 品牌调性不符 |
| 竞品提及 | [竞品博主名]、[竞品品牌名] | 除经创作者批准的对比内容 |
| 导流话术 | 微信搜索、加我好友、点击链接 | 平台违规风险 |
| 夸大表达 | 史上最强、全网第一、没有之一 | 品牌真实人设不符 |

### 3.2 句式风格

**推荐句式特征：**
- 短句为主，单句不超过 25 字
- 多用主动语态：「我发现」而非「被发现」
- 善用转折制造节奏感：「但是」「不过」「话说回来」
- 口语化连接词：「说白了」「换句话说」「你想啊」
- 适度使用反问增强互动感：「是不是？」「有没有同感？」

**避免的句式：**
- 长定语从句（读起来喘不上气的那种）
- 书面语堆砌（「鉴于上述情况，我们认为……」）
- 网络烂梗滥用（过时或争议性网络用语）

### 3.3 标点符号规范

| 符号 | 使用场景 | 注意 |
|------|---------|------|
| ！ | 表达惊喜或强调，每段最多1个 | 不要连用「！！！」 |
| ？ | 提问和反问 | 可连用「？？」表示强调疑问，但最多2个 |
| —— | 转折、补充说明 | 代替括号，更口语化 |
| 「」 | 强调词、引用、宗门术语 | 统一使用直角引号 |
| … | 表示省略、悬念 | 固定用3个点「…」而非6个 |

## 四、平台语气微调

同一内容在不同平台发布时，需根据平台用户习惯微调语气：

| 平台 | 语气微调方向 | 示例差异 |
|------|-------------|---------|
| **抖音** | 更口语、更短、更有节奏感 | 「兄弟们，这个动作你绝对做错过——」 |
| **小红书** | 更细腻、更有条理、适度使用分隔符 | 「姐妹们收藏这篇！减脂期早餐这样吃👇」 |
| **B站** | 更详细、可以更技术流、弹幕互动感 | 「今天详细拆解一下这个动作的生物力学原理」 |
| **微博** | 更碎片化、更即时、话题感强 | 「刚练完，分享一个冷知识：#健身冷知识#」 |
| **微信** | 更深度、更有温度、长文友好 | 「最近收到很多留言问我关于减脂平台期的事，今天认真聊聊」 |

## 五、品牌声音自检清单

每条文案发布前，对照以下清单自检：

- [ ] 读出来像是"一个人在说话"，而不是"一篇文章在写字"？
- [ ] 去掉品牌名，粉丝能认出这是我们的内容吗？
- [ ] 有没有给出具体可执行的建议，而不只是空泛的道理？
- [ ] 语气是否和内容类型匹配（参考语气光谱）？
- [ ] 有没有使用禁用词清单中的词汇？
- [ ] 宗门相关内容是否使用了标准术语？
- [ ] 适合大声朗读吗？读起来会不会觉得尴尬？

## 六、声音演进规则

品牌声音不是一成不变的。以下情况需要更新本指南：

| 触发条件 | 更新动作 |
|---------|---------|
| 粉丝量突破重大里程碑（如 50万、100万） | 评估人设是否需要"升级"，增加权威感 |
| 开辟新内容领域 | 补充该领域的语气规范 |
| 粉丝画像发生显著变化 | 调整称呼方式和语气倾向 |
| 季度复盘发现互动率持续下滑 | 排查是否为声音疲劳，考虑微调 |

**更新流程：** 由内容策划提出 → 创作者确认 → 更新本文档 → 团队全员同步
