## 一、内容支柱总览

内容支柱是团队所有选题和创作的"骨架"。所有内容必须归属于以下六大支柱之一，确保账号内容方向清晰、可持续、可量化。

```
                    ┌────────────────────┐
                    │   品牌使命         │
                    │ 科学·真实·有温度   │
                    └────────┬───────────┘
         ┌──────────┬───────┼───────┬──────────┬──────────┐
         ▼          ▼       ▼       ▼          ▼          ▼
    ┌─────────┐┌─────────┐┌────┐┌─────────┐┌─────────┐┌─────────┐
    │训练教程 ││营养饮食 ││生活││热点借势 ││品牌合作 ││宗门IP  │
    │  35%    ││  25%    ││20% ││  10%    ││  ≤10%   ││ 贯穿   │
    └─────────┘└─────────┘└────┘└─────────┘└─────────┘└─────────┘
```

## 二、六大支柱详解

### 支柱一：训练教程（35%）

**定位：** 账号的核心价值输出，建立专业壁垒。

| 维度 | 说明 |
|------|------|
| 内容方向 | 动作教学、训练计划、动作纠错、居家/健身房训练方案 |
| 目标受众 | 健身新手到中级训练者（训练经验 0-3 年） |
| 核心价值 | 让用户"学到一个马上能用的动作或方法" |
| 关键指标 | 完播率 ≥ 40%、收藏率 ≥ 8% |

**子类型：**

| 子类型 | 占比 | 示例选题 |
|--------|------|---------|
| 单动作教学 | 40% | 「硬拉总是腰疼？你少了这一步」 |
| 完整训练计划 | 25% | 「新手友好！一周四练计划（附动作演示）」 |
| 动作纠错 | 20% | 「深蹲膝盖内扣？3个方法立刻改善」 |
| 居家替代方案 | 15% | 「没有哑铃也能练背？5个徒手动作」 |

**选题红线：**
- 不教超出自身能力范围的高难度动作（如奥林匹克举重），除非有专业教练合作
- 不推荐未经验证的"偏方训练法"
- 涉及伤病康复的内容必须声明"建议咨询专业医生"

---

### 支柱二：营养饮食（25%）

**定位：** "三分练七分吃"的知识补充，实用导向。

| 维度 | 说明 |
|------|------|
| 内容方向 | 食谱推荐、营养知识科普、饮食误区辟谣、购物/备餐攻略 |
| 目标受众 | 关注体重管理和健康饮食的人群 |
| 核心价值 | 让用户"知道今天该吃什么、怎么吃" |
| 关键指标 | 收藏率 ≥ 10%、转发率 ≥ 3% |

**子类型：**

| 子类型 | 占比 | 示例选题 |
|--------|------|---------|
| 实用食谱 | 35% | 「减脂期午餐便当，10分钟搞定」 |
| 营养科普 | 30% | 「蛋白质到底要吃多少？一个公式算清楚」 |
| 饮食误区 | 20% | 「这5种"健康食品"其实热量爆炸」 |
| 购物/备餐攻略 | 15% | 「健身人的超市购物车，一周300块搞定」 |

**选题红线：**
- 不推荐极端饮食法（如完全断碳、极低卡路里）
- 不宣称食物有"治疗"功效
- 涉及补剂推荐需标注"个人体验，因人而异"

---

### 支柱三：生活方式（20%）

**定位：** 展示真实生活，拉近与粉丝的距离，建立情感连接。

| 维度 | 说明 |
|------|------|
| 内容方向 | 日常vlog、训练打卡、心态分享、健身生活记录 |
| 目标受众 | 已关注的粉丝（强化忠诚度） |
| 核心价值 | 让用户"觉得这个人真实、有温度、值得追" |
| 关键指标 | 评论率 ≥ 5%、关注转化率 ≥ 2% |

**子类型：**

| 子类型 | 占比 | 示例选题 |
|--------|------|---------|
| 日常训练vlog | 35% | 「今天的腿练日，差点站不起来」 |
| 心态/感悟 | 30% | 「练了一年，最想对新手说的3句话」 |
| 生活记录 | 20% | 「健身博主的周末是怎么过的」 |
| 里程碑分享 | 15% | 「从0开始的第100天，变化远不止身材」 |

**选题红线：**
- 不过度暴露私生活（家庭成员出镜需本人同意）
- 不贩卖焦虑或制造身材对比压力
- 负面情绪内容需以正向收尾

---

### 支柱四：热点借势（10%）

**定位：** 借助平台热点和节日节点获取流量，扩大曝光。

| 维度 | 说明 |
|------|------|
| 内容方向 | 热门话题关联、节日主题内容、社会热点解读 |
| 目标受众 | 泛健身兴趣人群（拉新为主） |
| 核心价值 | 让用户"因为热点进来，因为内容留下" |
| 关键指标 | 播放量增幅 ≥ 50%（相比常规内容） |

**操作规范：**

| 规则 | 说明 |
|------|------|
| 相关性原则 | 热点必须与健身/健康生活能自然关联，不强蹭 |
| 时效性原则 | 热点内容需在 24 小时内完成创作发布 |
| 安全性原则 | 不碰政治、灾难、争议性社会事件 |
| 回归原则 | 热点是"入口"，内容必须回归到健身主题 |

**年度固定节点日历：**

| 月份 | 节点 | 选题方向 |
|------|------|---------|
| 1月 | 元旦/新年 | 新年健身计划、年度复盘 |
| 2月 | 春节/情人节 | 春节饮食不发胖、情侣健身 |
| 3月 | 女神节 | 女性力量训练专题 |
| 4月 | 清明/春季 | 户外训练、春季饮食 |
| 5月 | 劳动节/520 | 假期训练计划 |
| 6月 | 618/儿童节 | 好物推荐、亲子运动 |
| 7-8月 | 暑假/夏天 | 夏日身材、游泳、户外 |
| 9月 | 开学季 | 大学生健身入门 |
| 10月 | 国庆/秋季 | 假期训练、换季饮食 |
| 11月 | 双十一 | 健身装备推荐 |
| 12月 | 圣诞/年末 | 年度总结、冬季训练 |

### 支柱五：品牌合作（≤10%）

**定位：** 商业变现通道，需严格控制比例和质量。

| 维度 | 说明 |
|------|------|
| 内容方向 | 产品评测、品牌合作推广、好物推荐 |
| 目标受众 | 有消费意向的活跃粉丝 |
| 核心价值 | 让用户"信任推荐，觉得这个东西值得买" |
| 关键指标 | 转化率（由品牌方提供）、负面评论率 < 5% |

**合作红线：**

| 规则 | 说明 |
|------|------|
| 亲测原则 | 所有推荐产品必须本人使用至少 2 周 |
| 透明原则 | 商务内容必须标注「广告」或「合作」 |
| 频率上限 | 每月商务内容不超过总发布量的 10% |
| 品类限制 | 不接减肥药、代餐（除品质可靠品牌）、医疗器械类 |
| 排他期 | 同品类合作需间隔至少 30 天 |

---

### 支柱六：宗门 IP（贯穿所有内容）

**定位：** 不独立占比，而是作为"文化层"贯穿其他所有支柱。

| 维度 | 说明 |
|------|------|
| 表现形式 | 宗门术语、专属称呼、仪式感元素、社群活动 |
| 核心价值 | 建立粉丝归属感和社群认同感 |
| 关键指标 | 宗门术语使用率 ≥ 20%（评论区）、UGC 产出 ≥ 50条/月 |

**详见 →** [宗门IP手册](super-ip.md)

## 三、内容配比管理

### 月度配比目标

| 支柱 | 最低占比 | 目标占比 | 最高占比 |
|------|---------|---------|---------|
| 训练教程 | 30% | 35% | 40% |
| 营养饮食 | 20% | 25% | 30% |
| 生活方式 | 15% | 20% | 25% |
| 热点借势 | 5% | 10% | 15% |
| 品牌合作 | 0% | ≤10% | 10% |

### 配比偏差预警

- 任一支柱偏离目标占比 ±10% 时，内容策划需在周会中说明原因
- 连续两周偏离 ±15%，需调整下周内容日历进行纠偏
- 商务内容超过 15% 需创作者特批

### 配比跟踪方式

每周五数据复盘时统计本周各支柱实际发布数量，与目标对比，记录在周报 Issue 中。

## 四、支柱演进规则

| 触发条件 | 调整动作 |
|---------|---------|
| 某支柱内容连续 4 周互动率低于均值 50% | 评估是否降低占比或调整子类型 |
| 粉丝调研显示强烈的新内容需求 | 评估是否增设新支柱或子类型 |
| 账号进入新发展阶段（如开启直播） | 增加对应支柱或调整配比 |
| 季度复盘 | 全面评估各支柱数据，微调占比 |

**调整流程：** 数据分析师提出数据依据 → 内容策划提出调整方案 → 创作者审批 → 更新本文档 → 团队同步
