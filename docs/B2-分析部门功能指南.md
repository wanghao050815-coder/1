## 数据结构

### MetricsSnapshot

```python
@dataclass
class MetricsSnapshot:
    timestamp: str          # ISO 8601 时间戳
    followers: int          # 粉丝数
    follower_change: int    # 日增长数
    engagement_rate: float  # 互动率
    completion_rate: float  # 完播率
    comment_rate: float     # 评论率
    share_rate: float       # 转发率
    save_rate: float        # 收藏率
```

### 健康度评分权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 粉丝增长 | 30% | 日增长数 / 50（日增5000+为满分） |
| 互动率 | 25% | engagement_rate * 2000（5%为满分） |
| 完播率 | 20% | completion_rate * 100 |
| 互动细分 | 15% | (comment_rate + share_rate) * 5000 |
| 收藏率 | 10% | save_rate * 667 |

### 异常检测

使用 3-sigma 规则：
- 3σ < deviation：中等异常（medium）
- 3.5σ < deviation：高度异常（high）
- 4σ < deviation：严重异常（critical）

## 关键指标说明

### 健康度评分范围

| 评分 | 等级 | 含义 |
|------|------|------|
| 85-100 | 优秀 (Excellent) | 账号表现卓越，各项指标都很出色 |
| 70-85 | 良好 (Good) | 账号表现稳定，有小的改进空间 |
| 50-70 | 一般 (Fair) | 账号表现一般，需要重点改进 |
| <50 | 较差 (Poor) | 账号表现不佳，需要采取行动 |

### 互动率公式

```
engagement_rate = (likes + comments + shares) / views
```

目标：5% 或以上

### 完播率定义

```
completion_rate = 完播数 / 总播放数
```

目标：35% 或以上（行业平均）

## 常见问题

### Q: 如何自定义健康度权重？

修改 `MetricsCalculator.calculate_health_score()` 中的权重系数（当前为 0.30, 0.25, 0.20, 0.15, 0.10）。

### Q: 异常检测的敏感度如何调整？

修改 3-sigma 的系数（当前为 3.0、3.5、4.0），改成 2.5 或 2.0 可增加敏感度。

### Q: 趋势预测精度如何提高？

当前使用线性回归。可尝试：
- 增加历史数据点数
- 使用多项式回归或指数平滑
- 考虑季节性因素

### Q: 如何导出报告为 HTML？

当前支持 Markdown 导出。可使用 pandoc 等工具转换：
```bash
pandoc report.md -o report.html
```
