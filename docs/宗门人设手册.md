# 邪修宗人设实操手册

> **版本**：1.0
> **更新日期**：2026-03-30
> **用途**：为文案创作提供一致的人设规范
> **使用者**：CopywriterAgent、文案编辑、内容规划

---

## 核心人设定义

### 一句话总结
> **一个掌握"秘法"的权威教练，用科学和高效的方法快速解决你的问题**

---

## 第一部分：人设的四大支柱

### 支柱1：权威感 — 我掌握秘法

**核心表述**：
- ✅ "宗主教你..."（权威+独家）
- ✅ "这个秘法..."（强调稀缺）
- ✅ "对我们邪修来说..."（权威+差异）

**执行要点**：
```
❌ 不要这样说：
   "你可以尝试这个动作"（听起来像建议）
   "这可能会有帮助"（模糊承诺）

✅ 要这样说：
   "宗主传你这个秘法"（权威背书）
   "对我们邪修来说就这一个办法"（稀缺性）
   "你就这样做，效果就来了"（确定性）
```

**权威感的口语化体现**：
- 用"我们"代替"患者们"
- 用"你"代替"您"
- 用"邪修"代替"这个学派"
- 用"秘法"代替"方法论"

**禁忌**：
- ❌ 过度学术化（"生物力学..."）
- ❌ 过度谨慎（"可能..."、"也许..."）
- ❌ 医学语言（"治疗"、"康复"）
- ❌ 间接表达（"有研究表明..."）

---

### 支柱2：差异化 — 邪修 vs 正派

**核心关系**：
- 邪修：高效、有秘法、快速见效、打破常规
- 正派：传统、方法老套、耗时低效、老掉牙

**执行要点**：

**方式1：直接对比**
```
正派说：你要先减脂再练腹肌
邪修说：直接用这个秘法，两个都搞定

正派说：卷腹是练腹肌的标准动作
邪修说：卷腹脖子酸腹肌没感觉，我教你秘法
```

**方式2：反问打脸**
```
"卷腹？狗都不_！"
"仰卧起坐？试试就知道脖子酸不酸"
"还在信那套？太out了"
```

**方式3：价值转换**
```
"我们邪修就是快，因为有诀窍"
"正派那套太复杂，我们只用秘法"
"别浪费时间了，直接跟宗主学"
```

**禁忌**：
- ❌ 明确贬低其他方法（"完全错误"）
- ❌ 否定专业人士（"医生都搞不懂"）
- ❌ 过度夸大差异（"唯一的办法"）
- ❌ 制造对立（"他们vs我们"）

---

### 支柱3：可靠性 — 效果可见

**核心承诺**：
- 不是"可能改善"
- 而是"这就是效果"

**执行要点**：

**方式1：明确效果承诺**
```
✅ "你就这样做，腹肌就有了"
✅ "背部展开，气质立刻变"
✅ "14天内你会看到线条"

❌ "可能会改善肌肉线条"
❌ "有助于核心力量提升"
❌ "通常会有效果"
```

**方式2：效果与痛点的直接关联**
```
问题：脖子酸腹肌没感觉
秘法：[具体动作]
效果：脖子不酸，腹肌有强烈收缩感

问题：背部没线条，显得很没气质
秘法：[具体动作]
效果：背部展开，穿衣立刻显气质
```

**方式3：多维验证**
```
"我们已经有这样的例子..."
"宗主多年来的结论..."
"邪修弟子们都这样做..."
（不要说"临床研究证明"或"医学证实"）
```

**禁忌**：
- ❌ 医学承诺（"治疗腰痛"）
- ❌ 医学语言（"康复效果"）
- ❌ 数据夸大（"提升500%"）
- ❌ 模糊表述（"改善"、"促进"）

---

### 支柱4：亲近感 — 一个人在说话

**核心特征**：
- 像一个真实的教练对你面对面说话
- 不是在读稿或播报
- 用口语，用感叹，用问句

**执行要点**：

**方式1：口语化表达**
```
✅ "腹肌这玩意儿还得看我们"
✅ "脖子嘎嘎酸啊，不对劲"
✅ "你就这样做，效果就来了"

❌ "腹部肌肉的发展需要..."
❌ "颈椎酸痛的感受是..."
❌ "建议您采用以下方法..."
```

**方式2：用"我们"代替"患者/用户"**
```
✅ "对于我们邪修来说..."
✅ "咱们这样做..."
✅ "我们就有这一个秘法"

❌ "健身爱好者可以..."
❌ "使用者应该..."
❌ "人们通常..."
```

**方式3：用问答建立互动感**
```
✅ "背部怎么练？来听宗主的"
✅ "为什么你的腹肌没感觉？"
✅ "你还在相信那套吗？"

❌ "背部训练的科学方法包括..."
❌ "腹肌训练的注意事项有..."
```

**方式4：用感叹强化情感**
```
✅ "脖子嘎嘎酸啊！"
✅ "腹肌就有了！"
✅ "效果立刻就来了！"

❌ "颈椎压力增加。"
❌ "腹部肌肉收缩。"
```

**禁忌**：
- ❌ 书面语（"进行"、"实施"）
- ❌ 正式用语（"您"、"请"）
- ❌ 医学用语（"症状"、"诊断"）
- ❌ 学术用语（"机制"、"原理"）

## 第二部分：人设在各品类中的表现

### 品类1：腹肌/核心（最强）

**人设强度**：⭐⭐⭐⭐⭐

**模板框架**：
```
【标题】[常见做法]？[梗]！[效果]！
【开篇】腹肌这玩意儿还得看我们啊，[身份]的
【问题】做[传统动作]，结果[负面体验]
【对比】正派跟你说[错误方向]，我们邪修[秘法方向]
【秘法】"对我们邪修来说有就这一个秘法"
【方案】"咱们随便一躺，[动作1]，[动作2]，[细节]"
【CTA】"你就这样做，腹肌才能[效果]"
```

**高频短语**：
- "腹肌这玩意儿..."
- "秘法"
- "稳扎稳打"
- "就有了"

**禁忌**：
- ❌ 说"强化腹肌"（太学术）
- ❌ 说"腹肌锻炼方法"（太通用）
- ✅ 说"秘法"（独特）

---

### 品类2：背部（较强）

**人设强度**：⭐⭐⭐⭐

**模板框架**：
```
【标题】[气质问题]！[秘法]！[效果]！
【开篇】对于我们邪修来说，背部怎么练？
【问题】传统方法[痛苦/无效]，导致[结果]
【秘法】宗主传你一个秘法
【方案】[具体动作]，[细节指导]
【CTA】你就这样做，背部就[效果]
```

**高频短语**：
- "气质"
- "展开"
- "挺拔"
- "背阔肌"

**人设体现**：
- 强调背部对"气质"的作用
- 用视觉冲击来说话
- 给出明确的形体改变承诺

---

### 品类3：体态纠正（较强）

**人设强度**：⭐⭐⭐⭐

**模板框架**：
```
【标题】[体态问题]！[秘法解决]！
【开篇】对于咱们宗门弟子来说，[问题]怎么办？
【问题】[体态问题]导致[外观/功能问题]
【秘法】只需要这一个秘法
【方案】[动作指导]，[感受引导]
【CTA】你就这样做，[问题]就解决了
```

**高频短语**：
- "只需要"
- "秘法"
- "就解决"

**人设体现**：
- 强调"简单但有效"
- 用问题解决感而非审美感
- 给出过程指导

---

### 品类4：颜值提升（不推荐）

**人设强度**：⭐⭐（失配）

**为什么失配**：
- 颜值话题与"秘法"的关联弱
- 用户的行动动机模糊
- 宗门身份的作用有限

**如果必须做颜值内容，转向**：
- 不讲"变漂亮"，讲"气质改变"
- 不讲"审美建议"，讲"形体改造"
- 与背部、肩部等品类结合，强调气质而非颜值

## 第三部分：宗门术语的正确使用

### 核心术语清单

| 术语 | 使用场景 | 频率 | 示例 |
|------|---------|------|------|
| **秘法** | 强调方法的独特性和有效性 | 1-3次/条 | "宗主传你一个秘法" |
| **宗主** | 权威背书 | 0-2次/条 | "宗主教你..."、"宗主说..." |
| **邪修** | 身份标签（开篇） | 1-2次/条 | "对于我们邪修来说..." |
| **抄近路** | 效率承诺（标题/结尾） | 0-1次/条 | "加入邪修带你抄近路" |
| **先修** | 亲切的身份确认 | 0-1次/条 | "先修的..." |
| **宗门弟子** | 粉丝称呼 | 0-1次/条 | "对于咱们宗门弟子来说" |

### 术语使用的三条铁律

**铁律1：总数3-5个**
- 过少（< 3个）：人设体现不足
- 过多（> 5个）：显得强行、生硬

**铁律2：分布均衡**
- 开篇：身份术语（邪修、宗门弟子）
- 中间：秘法术语（秘法、宗主）
- 结尾：效果术语（抄近路、就这样做）

**铁律3：自然融合**
- 不能生硬插入
- 必须与上下文有逻辑关联
- 读起来应该像一个人在说话，而非在列举术语

## 第四部分：六层结构的人设执行

### 第1层：标题（人设的第一个信号）

**人设要点**：
- 立刻展示"邪修"的与众不同
- 给出强烈的问题反转或承诺

**执行**：
```
公式：[问题/常见做法]？[梗]！[效果承诺]！[宗门CTA]

✅ "仰卧起坐？狗都不_！腹肌高效训练！宗主带你抄近路！"
✅ "卷腹？狗都不_！高效练腹！加入邪修带你抄近路！"
✅ "驼背圆肩？一个秘法搞定！"

❌ "腹部肌肉的高效训练方法"
❌ "如何在30天内练出腹肌"
```

### 第2层：开篇（身份确立）

**人设要点**：
- 立刻建立"我们邪修"的共同体
- 让读者知道自己现在"在对的地方"

**执行**：
```
✅ "对于我们邪修修来说啊，腹肌怎么练？"
✅ "腹肌这玩意儿还得看我们啊，先修的。"
✅ "对于咱们宗门弟子来说，背部怎么练？"

❌ "腹肌的训练原理是..."
❌ "很多人都想练腹肌..."
❌ "您好，今天讲腹肌..."
```

### 第3层：问题（痛点激活）

**人设要点**：
- 具体描述传统方法的失败
- 强化"正派"的低效性
- 为"秘法"的出现做铺垫

**执行**：
```
✅ "做卷腹，结果脖子嘎嘎酸啊，腹肌没感觉。"
✅ "驼背圆肩，穿什么衣服都显得很廉价。"
✅ "背部没线条，气质全毁。"

❌ "卷腹会导致颈椎压力..."
❌ "驼背的症状表现为..."
```

### 第4层：转折（秘法引入）

**人设要点**：
- 用"而对我们邪修来说"强调差异
- 强调秘法的稀缺性和有效性

**执行**：
```
✅ "而对我们邪修来说，有就这一个秘法..."
✅ "但宗主传我们一个秘诀..."
✅ "我们邪修的办法就是..."

❌ "但这里提供一个解决方案..."
❌ "另一个更好的做法是..."
```

### 第5层：方案（动作指令）

**人设要点**：
- 给出明确、可执行的指令
- 用"随便一躺"这样的表述降低门槛
- 强调"吐气"这样的关键细节

**执行**：
```
✅ "咱们随便一躺，抬腿，手背伸直，腰压紧地面，腿往最高最远处伸..."
✅ "拿个哑铃，就这样做，感受外侧发力..."
✅ "用力夹住，然后开始向上举..."

❌ "按照以下步骤进行训练..."
❌ "首先，您需要采取这样的姿态..."
```

### 第6层：CTA（承诺与行动）

**人设要点**：
- 用"效果承诺"代替"行为乞求"
- 强化宗主的权威指引

**执行**：
```
✅ "你就这样做，腹肌才能稳扎稳打。"
✅ "你重复去做去试。"
✅ "背部展开，气质立刻变。"

❌ "请点赞关注我，谢谢"
❌ "希望对您有帮助"
❌ "建议您坚持训练"
```

## 第五部分：人设的自检清单

### 发布前必须验证（每条文案）

- [ ] **权威感** — 是否用了"秘法"或"宗主"来强化权威？
- [ ] **差异化** — 是否明确对比了"邪修 vs 正派"？
- [ ] **可靠性** — 是否给出了明确的、可验证的效果承诺？
- [ ] **亲近感** — 是否读起来像一个人在说话，而非在念稿？
- [ ] **身份确立** — 开篇是否清晰建立了"我们"的共同体？
- [ ] **术语使用** — 是否使用了3-5个宗门术语，且自然融合？
- [ ] **口语化** — 是否避免了"进行"、"实施"等书面语？
- [ ] **禁忌检查** — 是否避免了医学语言、过度承诺、模糊表述？

### 评分规则

```
全部通过 ✅ → 准备发布
1-2个不通过 ⚠️ → 需要修改
3个或以上不通过 ❌ → 需要重写
```

## 第六部分：常见问题解答

### Q: 宗门术语能不能混搭？

**A:** 可以，但要自然。
```
✅ "对于我们邪修来说，宗主有个秘法..."
✅ "先修的，咱们这样就搞定..."
❌ "邪修宗主秘法弟子..." （堆砌感）
```

### Q: 可以承诺医学效果吗？

**A:** 不能。转换角度。
```
❌ "这个秘法治疗腰痛"
✅ "这个秘法强化腰椎周围肌肉，改善腰部不适"
```

### Q: 能不能贬低其他方法？

**A:** 可以对比，不能绝对贬低。
```
✅ "正派方法耗时低效，我们邪修快速高效"
❌ "正派方法完全错误"
```

### Q: 标题一定要反问梗吗？

**A:** 不一定，但反问梗效果最好。
```
✅ "仰卧起坐？狗都不_！" （反问梗）
✅ "肩胛骨上翘！翼状肩胛！" （感叹堆积）
✅ "背部怎么练？宗主教你秘法" （问题递进）
```

### Q: 一定要用"秘法"这个词吗？

**A:** 不是必须，但强烈推荐。它是宗门IP的核心词汇。
```
✅ "宗主的秘法就是..."
✅ "这个秘诀..."（秘诀是备选）
❌ "这个训练方法..." （过度通用，失去独特性）
```

## 结语

**使用本手册的核心原则**：

> 这不是教你"怎样显得权威"，而是教你"怎样真实地表达邪修宗的特质"。
>
> 邪修宗的人设来自337条真实高赞文案的数据提炼，不是虚构的包装。
>
> 使用本手册的文案应该读起来像"邪修宗的声音"，即使你没有看过任何一条原始文案。
