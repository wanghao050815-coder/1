## 二、高赞文案标准结构（6层模型）

基于前5名高互动文案（赞数 > 50,000）提炼的标准结构：

```
【标题】反问/否定梗 + 效果承诺
    ↓
【开篇】建立身份（"对于我们邪修来说"）
    ↓
【问题】具体痛点描述（"做卷腹脖子酸腹肌没感觉"）
    ↓
【转折】稀缺宣言（"对我们邪修来说有就这一个秘法"）
    ↓
【方案】简洁动作指令（"随便一躺，抬腿，吐气..."）
    ↓
【CTA】直接承诺（"你就这样做，腹肌才能稳扎稳打"）
```

### 最高赞案例（232,149赞）完整拆解：

| 层级 | 内容 | 技巧 |
|------|------|------|
| 标题 | "仰卧起坐？狗都不_！腹肌高效训练！宗主带你抄近路！" | 反问+梗+效果承诺 |
| 开篇 | "腹肌这玩意儿还得看我们啊，先修的。" | 身份建立+口语化 |
| 问题 | "想练腹做卷腹，结果他妈脖子嘎嘎酸啊，腹肌没感觉。" | 痛点精准+情绪化 |
| 转折 | "对于我们邪修修来说有就这一个秘法" | 稀缺性+宗门身份 |
| 方案 | "咱们随便一躺，抬腿，手背伸直，腰压紧地面..." | 降低门槛+具体指令 |
| CTA | "你就这样做，你的腹肌才能稳扎稳打。" | 直接承诺+可信 |

## 五、句式特征

### 数据统计
- **正文平均字数**：103字
- **标题平均字数**：19字
- **平均句长**：26字
- **风格**：100% 现代口语，无文言文

### 核心句式模板

**开篇句式**（身份建立）：
```
"对于我们[邪修/邪修修/宗门弟子]来说啊，[部位/问题]怎么练？"
```

**问题句式**（痛点描述）：
```
"[正派/传统]跟你说啊，你要[传统做法]。结果[负面结果]。"
```

**转折句式**（秘法引出）：
```
"而对我们[邪修]来说，[就/有就]这一个秘法，..."
```

**方案句式**（动作指令）：
```
"咱们随便一[躺/站]，[动作1]，[动作2]，吐气，[关键细节]..."
```

**收尾句式**（效果承诺）：
```
"你就这样做，[部位]就[具体效果]了。"
"你重复去做去试。"
```

## 八、写作禁忌（基于数据验证）

### 绝对不做
1. **不用虚构术语** — 只用上方术语表中的真实术语
2. **不用文言文** — 全部口语化表达
3. **不用模糊承诺** — "会改善" ❌ → "腹肌就有了" ✅
4. **不用数字过多** — 真实文案中精确数字承诺很少
5. **不用乞求式CTA** — "求点赞" ❌ → "你就这样做" ✅
6. **不用书面语** — "进行训练" ❌ → "练" ✅

### 注意事项
- 宗门术语每条文案 3-5 个，不可超过
- "秘法"是最核心的包装词，优先使用
- "正派"用作对比对象，不可贬低
- 保持"一个人在说话"的感觉，像教练面对面指导
